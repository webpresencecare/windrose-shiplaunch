# Security policy

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues, pull requests, discussions or support forums.**

Report a vulnerability privately through GitHub: [Report a vulnerability](https://github.com/webpresencecare/windrose-shiplaunch/security/advisories/new) (the Security tab of this repository). Only I can read it.

Soon, Windrose Shiplaunch will also take part in Patchstack's vulnerability disclosure program; this page will then link it.

## What happens next

1. I confirm that I received your report, and we discuss it in the private advisory.
2. I fix a valid report within 30 days and tell you when the fixed version is released.
3. I publish the advisory after the fix is released, with a CVE where it applies, and credit you if you wish.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: the code in this repository, as released. Out of scope: WordPress core, Multisite Language Switcher and other third-party plugins and themes (report to their maintainers), and issues that need a network administrator account to exploit against their own network, unless they cross a site boundary they should not.
